# Scientific methods and limits

- The source ZIP contains requirements and numerical vectors, not the referenced textbook PDF. Only NDVI and the transformations are attributed to the source scope stated by the package. The remaining indices are explicitly an expanded product catalog.
- Catalog equations are parsed through an arithmetic AST whitelist. No arbitrary Python evaluation is used. Near-zero denominators (<1e-6), invalid square roots and input NoData produce masked NaN, never a numerical zero substitute. Outputs are not globally clamped.
- Radiometric input uses verified STAC scale/offset metadata or GDAL scale/offset tags. The pure calibration function also tests SAFE's `(DN+BOA_ADD_OFFSET)/QUANTIFICATION_VALUE`; an automated SAFE archive ingestion workflow is not implemented. Unknown metadata is refused. Conflicting Earth Search legacy offset flags are refused; use Collection 1. Source metadata accuracy remains a provider responsibility.
- Reflectance is float32; PCA model fitting uses float64. Negative and >1 corrected reflectances are preserved. PCA signs are stabilized, sample selection is deterministic, and model metadata supports inverse mapping. Very large AOIs hit a pixel/memory limit before reads.
- Target grids use the native coarsest input resolution by default. AOIs crossing the antimeridian, UTM zones or the supported UTM latitude range are explicitly refused. Boundary clipping uses pixel-center inclusion. SCL is nearest-neighbor; spectral bands use reported nearest/bilinear resampling. Bilinear boundaries and geodesic area can differ from raster pixel-count area.
- Exact masks are distinct from zeros. Stats exclude NoData and report valid fraction against rasterized AOI pixels. RGB/FCC contrast never changes the stored reflectances. Numeric map legends use the global result percentiles; tile colorization is not independently normalized.
- Per-band PCA and RGB results are stored in a multiband Float32 COG, with each band readable separately in GIS. Separate component downloads and an interactive component selector are future refinements.
- NDWI_MCF is Green/NIR (McFeeters); NDMI is NIR/SWIR moisture. MNDWI and NDSI_SNOW share algebra with different interpretation. CI indices are proxies, not measured chlorophyll concentrations. NBR does not establish validated fire severity.
- Temporal subtraction is later-minus-earlier, with matching index ID and AOI. Inputs are reprojected deliberately to the coarser input grid. No automated thematic classification is performed.
- One real NDVI scene/window was validated on 17 November 2026; this is not broad validation across all providers, baselines and geographies. All catalog equations have deterministic numerical and raster-fixture tests.
- COGs were reopened by Rasterio and retain CRS, Float32, internal masks and COG layout. Independent headless QGIS 3.44.8 comparison now passes for NDVI, NDWI_MCF, NDBI and EVI (maximum error 2.3842e-7), and QGIS reads the COG grid, CRS and masks correctly. Native mixed-resolution calculator reads differed until raw DN inputs were explicitly aligned with QGIS-bundled GDAL Warp; the reference comparison uses declared nearest-neighbor alignment. The comparison evaluates algebra on valid pixels and COG mask round trips; it does not independently derive the SCL cloud classification. Manual desktop GUI review remains unverified. GeoTIFFs may be small enough not to need an overview; larger COGs use automatic overviews.
